# Bem vindo(a) ao Forumhub ONE 📚

### Sobre o projeto 🖥️
O **Forumhub** é um projeto/Desafio do programa ONE desenvolvido para gerenciar um fórum de estudos, focando na implementação de toda a parte de back-end utilizando API REST e o framework Spring Boot.

---

## 🎯 OBJETIVOS
O objetivo deste projeto é implementar uma API REST com as seguintes funcionalidades:

- 🔄 Rotas implementadas seguindo as melhores práticas do modelo REST;
- ✅ Validações realizadas de acordo com as regras de negócio;
- 🗄️ Implementação de uma base de dados relacional para a persistência de informações;
- 🔐 Serviço de autenticação/autorização para restringir o acesso às informações.

---

## 🔗 ROTAS

### **📝 Topico**
- **POST**: Criação de tópico: http://localhost:8080/topico

- **GET**: Listar todos os tópicos: http://localhost:8080/topico

- **GET**: Detalhamento de um tópico pelo ID: http://localhost:8080/topico/{id}

- **PUT**: Atualizar tópico: http://localhost:8080/topico/{id}

- **DELETE**: Exclusão lógica de um tópico pelo ID: http://localhost:8080/topico/{id}

### **👤 Usuario**
- **POST**: Criação de usuário autorizado a acessar a API: http://localhost:8080/login
